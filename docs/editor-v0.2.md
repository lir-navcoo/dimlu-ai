# 画布点选与结构编辑 v0.2

本阶段增加画布选择、编辑/预览模式，以及节点移动、复制。应用 Schema 继续保持 v0.1.0；选择、悬停、模式与边框全部属于编辑器会话状态。

## 操作

页面默认处于编辑模式。点击组件同步选择组件树和属性面板；内部原生 React 控件属于宿主物料时，选择对应的 Schema 节点。例如点击采购明细内部的输入框，选择 `react.purchaseItems`，不会把 TSX 内部结构转成 Schema。

右侧“结构”区域支持同级上移、下移、复制，以及移动到页面、任意可接收子节点的容器或具名插槽末尾。目标列表排除被移动节点及其整个子树，命令层也独立检查并拒绝循环。选择容器仍可以通过组件树完成。

编辑模式拦截画布内的指针、点击、输入、提交、重置和键盘激活事件，防止选择组件同时触发业务动作。业务控件从 Tab 顺序暂时移除，预览模式恢复原 tabindex；组件树按钮和结构操作可通过键盘操作，Escape 清除画布选择。预览模式保留原生 React 事件。

模式切换和节点选择不会修改应用、创建撤销历史或重建运行实例，表单输入及 React 局部状态保持。有效 Schema 修改仍会重建实例并取消旧动作，与 v0.1 一致。

## 命令语义

| 命令                                     | 行为                                                                      |
| ---------------------------------------- | ------------------------------------------------------------------------- |
| `moveNode(pageId, nodeId, target)`       | 保留节点、子节点、动作 ID 与绑定，先移除源节点，再插入目标列表            |
| `duplicateNode(pageId, nodeId, target?)` | 深拷贝完整子树，为每个节点和动作调用重建页面内唯一 ID，默认插在原节点后面 |

`target` 沿用 `{ parentId?, slot?, index? }`。移动的 `index` 表示**源节点移除后的目标索引**，省略表示目标末尾；根节点列表省略 `parentId`。复制到指定位置可传入 target，省略则复制到同级下一项。

所有操作都先在草稿中执行，再通过同一编译器检查，接受后一次发布，成为一步撤销记录。失败保持文档、选择和历史不变；无变化移动不创建历史。移动或复制成功会选中结果，撤销恢复之前的选择。当前支持同页移动与复制。

复制保持 stateRef、fieldRef、formId、作用域表达式、事件输入和命名空间扩展内容；它复制视图结构，表单模型和状态仍按原引用共享。扩展是宿主的 opaque JSON，内部字符串即便与旧节点 ID 相同也不会擅自替换。后续若需要复制业务模型，应提供单独的模型复制命令和引用迁移契约。

## 作用域检查

`packages/editor/scope.ts` 遍历源与目标的祖先，计算 repeat 和 slot 暴露的 scope 名称，并分析子树内的表达式 AST。被使用的已有外部名称，在目标位置必须仍然存在；例如卡片标题依赖 `scope.record`，移到页面根会被拒绝，移到提供 record 的另一个插槽则允许。

节点自己声明的 repeat 和内部 slot 会重新建立局部作用域，因此整棵重复容器或插槽卡片可以移动。`repeat.items` 使用外部作用域，`repeat.key`、when、props 和事件参数使用循环局部作用域。动态 `scope[...]` 和直接使用 scope 对象时，保守要求保留源处的所有外部名称。

此检查保证现有名称不会因移动而消失，不推断数据类型或证明运行结果。相同名称在不同插槽可能代表不同的数据。全量导入仍使用现有 Schema 编译校验，尚未扩展为完整的静态作用域类型系统。

## React 与画布分层

`RuntimeRenderer` 增加可选 `nodeDecorator`：宿主可在每个实际渲染的节点实例外装饰内容，获得 NodeSchema 和稳定 instanceKey。普通运行环境不传入该选项，维持原有输出。

编辑宿主提供稳定的 NodeHost，使用 `display: contents` 包裹实际物料并附加节点和实例标记。编辑和预览模式共用相同 decorator，避免因切换包装层而卸载原生 React 组件。物料 props 和组件实现无须增加选中状态或编辑事件。

画布通过最近的节点标记选择 Schema 节点，通过物料 DOM 实际矩形计算覆盖边框。边框放在独立、禁止指针交互的覆盖层，通过 ResizeObserver、MutationObserver、窗口 resize、滚动及字体加载调度测量。循环节点的同一份定义对应多个 instanceKey，选中后同时标记所有可见实例，修改作用于共享定义。

NodeHost 在编辑宿主的预览模式也存在；`display: contents` 保持 flex/grid 的几何布局，但 DOM 直接子级选择器仍会受到包装影响。现有物料的相关样式已适配。后续接入依赖表格语义、Portal、Shadow DOM、纯文本 Fragment 或严格 DOM 层级的第三方物料时，需要专门的画布适配；当前不承诺通用无侵入 DOM 映射。无可测量 DOM 的空/隐藏节点可以通过组件树操作。

编辑模式仅拦截本画布的 UI 交互；页面 onEnter、组件生命周期和已经开始的异步动作仍按运行时规则执行。这不是第三方代码沙箱。

## 验证与下一步

已验证命令原子性、索引语义、循环拒绝、插槽和循环作用域、子树与动作 ID 重建、撤销重做、JSON 往返、画布和树同步、编辑事件拦截、表单与原生 Hook 状态保持。

实际浏览器完成“点击标题 → 复制 → 改标题 → 移入容器 → 撤销/重做 → 下载 JSON → 刷新 → 文件导入还原”。桌面截图见 `canvas-preview.png`，390px 下的循环节点选中效果见 `canvas-mobile-preview.png`。

拖放命中区域、空容器占位和目标位置提示已在 [编辑器 v0.3](./editor-v0.3.md) 实现；字段绑定面板可继续连接已有 FormDefinition。更大页面需要对 DOM 测量、全量编译和快照历史进行性能评估。
