# 工作台布局独立评审

评审方式：由另一位子 Agent 独立阅读当前实现与 `workbench-base-ui.jpg`，主 Agent 交叉核对。依据为源码、1280×720 截图和既有布局约定。本轮未运行浏览器，未修改界面实现。

## 结论

全高外壳、根页面不滚动、各内容面板独立滚动是合理的基础。下一轮应优先调整功能分区与常用操作的位置，保留现有 28px 编辑器控件、32px 业务控件以及 12–13px 常用文字。

当前右侧承担组件属性、完整结构操作、字段编辑、页面模型管理、添加组件与运行检查，主要编辑任务被辅助操作挤到了首屏下方。增加整体密度不能消除这些操作路径问题。

## 推荐布局

```text
┌─ 全局顶栏：项目 / 当前页面 / 撤销重做 / 文件菜单 / 预览 ─┐
├─ 左侧面板 ─────┬─ 中央视图区 ──────────┬─ 右侧属性 ──┤
│ 物料/结构/数据  │ 一行画布工具栏        │ 选中摘要      │
│ 搜索           │                      │ 内容属性      │
│ 当前面板       │ 可独立滚动的画布      │ 字段绑定摘要  │
│ 单层内容滚动   │                      │ 高级折叠组    │
│                ├──────────────────────┤ 单层内容滚动  │
│                │ 可展开调试区          │               │
│                │ Schema / 状态 / 日志  │               │
└────────────────┴──────────────────────┴───────────────┘
```

“数据”面板集中当前页面表单模型与字段管理；组件属性区保留绑定选择、当前字段摘要与跳转编辑入口。只呈现实际已支持的属性，不预设尚无配置能力的空页签。

左右栏初始可继续采用 224px / 304px，允许调整并记住用户选择；收栏阈值应考虑画布可用宽度。调试区打开后继续限制在应用全高内，不能重新引入根页面滚动。拖动调整尺寸时需要同步刷新画布测量，保留稳定拖放 DOM 与指针捕获。

## 实施顺序与验收

1. 重排属性区、取消强制切页签，并把草稿从面板局部生命周期中分离。这一阶段保持现有插入入口。
2. 左侧统一插入流程与页面模型入口，合并工具栏、移除重复标题。验证点击/键盘插入覆盖容器及具名插槽，再移除右侧重复入口。
3. 引入可调侧栏与底部调试区；验证 1280×720、1440×900 和窄屏下画布可用面积、焦点与滚动行为。

核心验收任务：选中标题后无需滚动即可编辑；连续插入三个组件无需反复切物料页签；修改未保存字段规则后切换面板、节点及断点，草稿仍能恢复；打开调试区后可同时选择组件与观察状态；各内容区滚动时根页面保持不动；选中、调整布局与开关面板不重建业务运行时。

## 保留与待验证

应保留全高布局、滚动边界、Base UI 焦点管理、运行时与编辑器 UI 分离、原生 React 组件扩展，以及非拖拽插入能力。

小屏左侧为模态 Dialog，遮罩与模态交互可能限制从物料抽屉直接拖向画布。本轮只核对到代码结构，未专项复现移动端拖放；后续需验证触屏拖放，并确保点击/键盘插入有完整可用路径。

相关实现：`src/App.tsx`、`src/editor/Editor.tsx`、`src/editor/FormPanel.tsx`、`src/editor/DragDrop.tsx`、`src/styles.css`。

## 实施与复审结果

上述 P1/P2 布局建议均已实施，当前约定见 [工作台布局](workbench-ui-plan.md)。原评审保留为问题与设计依据。

独立子 Agent 再次只读复审后补充的四项边界问题也已修复：窄桌面收缩过宽右栏、页面隔离的数据目标及手动字段选择恢复、全屏调试覆盖画布的焦点隔离、多指调整侧栏时锁定活动指针。主 Agent 完成桌面/窄屏实际拖放与内容滚动检查，自动回归覆盖草稿与布局状态。
