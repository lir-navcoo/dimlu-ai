# 字段绑定的编辑作用域

可视化编辑默认只允许输入组件绑定**最近的表单容器**所使用的模型。模型仍然属于页面，Schema 保留显式 `formId + fieldId` 引用；本次约束施加在编辑器，不改变运行时的引用协议。

## 可视化绑定

- 容器外不显示字段选择器和“新建并绑定字段”入口，提示先放入表单容器。
- 容器尚未绑定模型时，提示先配置该容器；不会穿透它去绑定外层表单。
- 容器内只列出其模型中类型兼容的字段。普通布局和具名插槽不打断所属表单关系。
- “新建并绑定字段”直接打开所属模型。切换管理模型会退出当前组件的创建流程，避免把其他模型字段绑定到当前组件。底层命令再次校验所属关系，过期界面不能绕过限制。

## 移动、复制与修改模型

表单内部重排、跨布局/插槽移动继续支持。移动或复制的子树包含已绑定字段时，目标位置必须继续提供同一模型的最近表单容器；否则预检与实际命令均拒绝，并提示先解除字段绑定。

这意味着拖出表单、跨不同模型表单移动、把含字段的布局整体拖出，也不会自动改绑或解除字段。移动整个表单容器会保留它自己的绑定，所以不受这一限制；复制整个表单仍共享原模型，不创建新的模型实例。

修改或解除表单容器的模型时，若会使其子字段失去匹配关系，操作被拒绝。即使两个模型含有相同字段 ID，也不自动迁移；先解除受影响组件的字段绑定，再修改容器并显式重新选择字段。内部另有独立表单的子树以其自己的最近容器为准。

拒绝操作不改变应用定义、选择、运行实例和撤销/重做记录。解除字段绑定沿用原规则：恢复字段定义中的初始值、标签等静态属性，不复制预览输入，也不删除字段模型。

## 显式定义的兼容

已有 Schema 或 JSON 导入中的跨区域绑定继续有效。右侧明确标注“容器外”，保留当前绑定和解除入口；不会自动改写定义。新绑定、插入、移动、复制仍遵循可视化编辑约束。

这为现有定义和原生 TSX 的 `useField`/`useForm` 扩展保留兼容性。当前不新增跨区域绑定的可视化创建入口；如有分区共用模型的业务需求，可另行设计显式关联交互。

## 验证

自动回归覆盖容器外/跨模型绑定拒绝、新建字段的原子回滚、子树移动、复制、具名插槽、未绑定容器边界、整表移动与复制、容器模型变更、JSON 导入兼容、撤销重做、字段选择过滤和无效键盘落点。
