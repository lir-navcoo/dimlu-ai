# Schema v0.1 与执行语义

状态：实验协议。版本标识为 `0.1.0`，当前只消费该版本；不自动猜测旧版本语义。

## 应用与依赖

应用字段：`schemaVersion`、稳定 `id`、`title`、`entryPageId`、`dependencies`、`pages`。页面具有 `id`、`title`、可选说明、状态定义、子节点和可选 `onEnter`。

依赖以注册 ID 映射到精确版本，如 `"ui.input": "1.0.0"`。注册缺失、版本不符、使用未声明的组件或动作都会阻止创建运行计划。物料当前由宿主本地导入，尚未实现远程加载及完整依赖锁文件。

核心对象不接受未知字段。`extensions` 的键使用 `namespace:name`，值必须为 JSON；未知扩展完整保留但不执行。未知执行能力会报错。协议升级需新增显式迁移函数，再进入当前版本校验流程。

## 身份与状态

页面 ID 在应用内唯一；节点 ID、动作调用 ID 分别在页面内唯一，包括插槽内部节点。ID 不作为展示文案使用。状态 ID 在页面内唯一，同时是 `state` 对象的属性名；v0.1 尚无独立的状态显示名和符号重命名工具。

状态定义包括 `id`、`type`、`initial`，类型为 string、number、boolean、array、object、null。number 要求有限数字；状态只能保存 JSON 数据。写入必须匹配类型，对象与数组整体替换。初始数据和写入值会复制并冻结，避免跨实例共享或绕过通知修改数据。

JSON 结构校验之外，还检查依赖、引用、重复 ID、初始类型、物料属性、事件与插槽契约。表达式的类型和局部作用域字段在运行时继续检查，尚未实现完整静态类型推导。

## 值与表达式

```json
{"kind":"literal","value":"标题"}
{"kind":"stateRef","stateId":"record","path":["name"]}
{"kind":"expression","language":"javascript","source":"state.quantity * state.price"}
```

根变量：

| 变量    | 语义                                                |
| ------- | --------------------------------------------------- |
| `state` | 当前页面状态，使用稳定状态 ID 访问                  |
| `forms` | 当前页面表单快照，values 按字段数据路径读取         |
| `scope` | 当前循环及插槽的局部变量                            |
| `event` | 当前 React 原生事件处理器收到的事件，仅动作输入可用 |

表达式由 JSEP 解析为 AST，再由解释器求值，不调用 `eval` 或 `Function`。当前支持字面量、数组、成员访问、算术、比较、逻辑和条件表达式；纯函数支持 `Number`、`String` 及 `Math.round/floor/ceil/min/max/abs`。实际语法解析范围以 JSEP 为准；不是完整 ECMAScript，也不宣称支持 JSX、模板字符串、赋值、语句、任意方法调用或 Hooks。

禁止通过 constructor、prototype、**proto** 访问对象。此限制和表达式子集用于收敛求值语义，不是运行任意第三方 JavaScript 的沙箱。

静态状态成员收集到对应状态 ID；动态状态索引与整体状态访问使用通配订阅。表达式解析缓存最多 500 项，不缓存上下文与执行结果。JSON 字符串只按字面量处理，不自动执行。

## 节点、条件与循环

节点必填：`id`、`component`、`props`。可选：`children`、`slots`、`on`、`when`、`repeat`、`extensions`，以及表单容器 formId 和字段 field 绑定。页面可选 forms，提供 fieldRef/formValues 值引用；表单支持 arrays、computed、整单 rules，计算能力在 dependencies.computations 声明精确版本。详见 [表单 v0.2](./form-v0.2.md)。

节点扩展保留 `extensions["dimlu:node-name"]` 作为可选的编辑器名称，值为规范字符串：非空、最多 80 个 Unicode 码点、首尾无空白、不含 C0 控制字符或 DEL。名称允许重复及中文、emoji、内部空格，不修改节点 ID、业务 props、字段名称或表达式。作者命令先 trim 输入，空白输入清除该键，再校验；导入不做规范化，非法保留值在原路径拒绝。清除只移除此键，保留其他扩展；没有作者名称时各展示入口沿用原回退名称。

这一保留规则只作用于节点；应用和页面的同名扩展仍按原通用 JSON 处理。其他未知扩展仍完整保留。旧 0.1.0 读者可读取合法的命名空间扩展但不认识名称能力；先前占用了此精确键且值不符合新约束的外部项目会被拒绝，不能视为任意旧项目无差别兼容。

节点名称与组件内容一起保存、复制和进入文档历史。静态组件跨页剪贴板仅精确放行这个合法名称键；同时存在任何其他扩展仍沿原策略拒绝整棵子树，不删除扩展后强行复制。同页及整页复制继续保留一般扩展，不能套用静态剪贴板的限制。名称不自动传入物料 props 或执行为代码；主动读取完整节点上下文的自定义物料仍可看到元数据。编辑器接受新运行计划时沿现有行为重建预览，名称修改不承诺保留当前运行实例状态。

`when` 必须求值为布尔值。无循环时在节点上下文判断；有循环时先创建每项作用域，再判断该项条件。

`repeat.items` 必须是数组，空数组渲染零项。`item` 和可选 `index` 声明局部变量，使用 `scope.<name>` 访问；未声明索引名时默认为 `index`。局部变量覆盖同名外层局部变量。重复 key 报错，key 必须为字符串或有限数字；稳定 key 用于维持排序前后 React 实例身份。

## React 物料与插槽

宿主分别注册能力契约和实际 React 组件。契约描述精确版本、属性类型及必填项、原生事件名、是否接收 children、具名插槽提供的参数。渲染前对动态属性继续做类型校验。

事件名沿用 React，如 `onChange`、`onClick`、`onSubmit`。React 事件对象直接进入动作表达式上下文。表单适配层在 onSubmit 前调用 preventDefault。绑定 formId 的容器使用 noValidate，由内核统一校验；未绑定表单继续使用浏览器约束校验。输入框使用真实 input。

插槽定义为 `params` 和 `children`。React 物料通过 `slots.header({record})` 调用插槽；定义中声明的参数被显式加入 `scope`。未声明的物料参数不会自动透传给子节点。

自定义组件直接使用 JSX/TSX 和 React Hooks。`useRuntimeState(stateId)` 可订阅页面状态，`useRuntime()` 可获取宿主运行实例。普通组件本地 `useState` 由 React 管理；创建新页面运行实例时整个物料子树重新挂载。

## 动作与并发

事件绑定是一组顺序动作。每项包含稳定调用 `id`、注册动作名、`input` 和可选 `resultTo`。每个动作执行前以最新页面状态计算参数，并检查契约类型；前项失败终止后续动作，不自动回滚已完成的动作。需要事务的业务由服务端动作适配器实现。

`state.set` 接收 `stateId` 和 `value`。其他动作由宿主注册，声明输入、可选输出类型，并接收 AbortSignal、只读状态和受生命周期保护的状态写入 API。

同一节点实例的同一事件再次触发，会取消上一条动作链。跨事件写入同一 `resultTo` 状态时，仅最新启动的结果绑定可以提交；过期请求即使不支持取消，也无法覆盖新结果。不同动作直接调用 setState 的跨通道业务协调仍由宿主负责。

页面进入后运行一次 `onEnter`。销毁页面会取消全部在途动作、移除订阅并禁止晚到结果写入。宿主动作仍应响应 AbortSignal 释放实际请求资源。React StrictMode 下销毁的实例不会复用。

## 错误与发布边界

Schema 错误阻止应用替换；节点渲染错误局部降级并记录节点 ID；动作错误保留失败状态，不伪造成功数据。诊断列表最多保留最近 100 条，不记录动作参数。

运行计划基于复制并冻结的应用定义，运行状态存放于各页面实例。当前不包含持久化、服务端执行器、权限、流程、跨版本数据迁移或生产发布管理。示例接口全为本地模拟。

## 布尔确认规则

字段规则新增 `mustBeTrue`（仅布尔字段），必须等于 true 才通过。`required` 保持原有非空语义，允许 false。导入、编辑和运行时使用同一规则定义，导出的 JSON Schema 已同步。详情见 [勾选框与开关](boolean-controls.md)。

数组值字段新增 `type: "array"` 与必需的 `itemType: "string" | "number"`，默认值为不重复的同类型数组。它不同于动态明细行 `forms[].arrays`；`required` 检查非空，`minLength / maxLength` 检查选项数量。单选绑定文本或数字，多选绑定数组。示例和空值语义见 [选择器](select.md)。
