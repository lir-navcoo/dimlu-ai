# 日期与时间

日期、月份、日期时间和时间共用紧凑外框与页面内选择面板。当前安装的 Base UI 1.9.0 没有公开 Calendar / DatePicker 组件；本项目使用官方 [Popover](https://base-ui.com/react/components/popover) 负责定位、Portal、关闭和焦点管理，自有日历与时间面板负责日期选择。没有依赖内部 temporal adapter，也不使用原生日期输入类型或 `showPicker()`。

## 操作

- 点击输入区域或右侧图标打开面板，也支持直接输入规范日期或时间。
- 单个日期、月份点选即应用。日期范围在同一个面板连续选择起止，完成后一次应用；未完成时取消不会修改原值。
- 时间和日期时间使用时、分、秒列，确认后应用。取消、Escape 或点外部关闭时不提交面板候选。
- 清空位于输入框内部；禁用状态不能打开或清空。错误继续由现有字段和日期格式校验提供。

面板按钮不会提交所在表单。进入选择面板属于同一个逻辑字段，真正离开输入框和面板时才触发字段离开行为。设计画布只选择组件，切换预览后才能使用选择面板。

## 值与兼容

| 模式     | Schema 格式           | 示例                  |
| -------- | --------------------- | --------------------- |
| 日期     | `YYYY-MM-DD`          | `2026-11-08`          |
| 月份     | `YYYY-MM`             | `2026-11`             |
| 时间     | `HH:mm` 或 `HH:mm:ss` | `09:30:15`            |
| 日期时间 | 本地日期 + `T` + 时间 | `2026-11-08T09:30:15` |

单值空值为 `''`，范围为空数组或两个字符串；仍复用 `ui.date` / `ui.time` 既有组件、字段契约与事件。日期时间不包含时区，不通过 UTC 转换存储。直接输入的未完成值继续按原字段规则显示错误，选择面板不会把未确认候选写入 Runtime。

Popover 复用工作台交互 Popup 层级，位于 Dialog/Drawer 之上；Tooltip 使用统一 Tip。没有新增快捷范围、业务禁用日期规则、时区配置或 Schema 迁移。

## 验证

019已正式验收：67个测试文件535项全量测试通过，Schema导出、严格TypeScript、构建、格式与独立源码评审通过。浏览器实测包含各模式、范围草稿、直接输入、清空、键盘与Drawer二级浮层；第一个Escape关闭选择面板并回焦，第二个关闭Drawer。显式Portal容器保留当前ShadowRoot样式根，否则使用所属document.body；时间列仅滚动自身，避免画布或抽屉位移。测试与浏览器证据见 [开发流水线](development-pipeline.md)。
