# 页面内核架构与决策

## 实施顺序

先做最小页面运行时，再以采购表单验证；列表和作用域插槽验证内核能够复用。表单内核建立在页面内核之上，字段模型与组件树分离；编辑器随后复用运行时及文档命令，实现属性编辑、画布选择与拖放编排。

## 分层

```text
Schema JSON / TypeScript authoring
                ↓
AJV 结构校验 + 引用/物料/表达式语义检查
                ↓
不可变应用定义 → 预解析运行计划
                ↓
独立页面实例：状态、表单 store、订阅、动作链、生命周期、诊断
                ↓
React 适配：useSyncExternalStore + 节点边界 + 原生组件
```

`packages/runtime` 不依赖 React。宿主提供注册表，运行时不认识实验台的布局或业务示例。React 适配通过 useSyncExternalStore 订阅节点依赖；检查器使用独立订阅，诊断增加不要求全树重新解析。

编辑层通过 `packages/editor` 的纯 TypeScript 文档 store 管理所有内容修改，复用同一编译器进行原子校验并维护撤销历史；`src/editor` 负责 React 编辑界面。物料编辑元数据、选择与历史都在应用 Schema 外，运行环境无需安装编辑器。属性修改、节点插入/删除/移动/复制、JSON 面板和文件导入共用文档命令。详见 [编辑器 v0.1](./editor-v0.1.md)。

本地项目存储属于编辑器适配层，`ProjectStorage` 只订阅已提交文档，使用注入的 Storage 接口保存版本化应用定义与可丢弃的选中位置。恢复先完整编译，损坏原文受保护；保存不序列化运行实例和未提交草稿，HMR/卸载会取消旧订阅与过期 timer。详见 [本地项目保存恢复](./project-storage-v0.1.md)。

本地存储架构在 N5 冻结副本完成独立验收，336 项测试及浏览器恢复、390px / 760px 确认对话框验证通过。N6 的 transport 草稿隔离与文案收尾已正式验收，340 项测试、协议导出、严格类型、构建、全源格式、浏览器与独立评审全部通过；准确交付状态见 [开发流水线](./development-pipeline.md)。

React 渲染器提供可选的 nodeDecorator 扩展点；画布宿主通过稳定 DOM 标记与覆盖层实现选择，不向 Schema 或业务组件 props 注入编辑状态。编辑/预览切换共用同一运行实例和组件身份，保留原生 React 状态。移动的作用域保护和复制时的 ID 重建在纯 TypeScript 文档层处理，详见 [编辑器 v0.2](./editor-v0.2.md)。

拖放以纯 DropIntent 表达节点前后或容器/插槽内部目标，文档预检与正式命令共用草稿准备和编译校验。React 宿主管理指针和键盘会话，通过 slotDecorator 提供具名插槽落点；会话不进入 Schema，拖动预览不修改文档，放置时只提交一条命令。详见 [编辑器 v0.3](./editor-v0.3.md)。

## React 原生代码优先

实际物料直接使用原生 React 组件。事件名及事件对象保持 React 形式。代码扩展写在 TSX / TypeScript 模块中，由正常构建链处理；不会要求用户把 Hook 或 JSX 填入 JSON 字符串。

Schema 的声明式绑定承担可序列化、可检查的配置工作；允许一个明确的 JavaScript 表达式子集处理简单计算。复杂逻辑使用组件或注册动作。将来若加入源码编辑，建议以受管理的 TSX 模块引用接入，复用正常模块编译和依赖版本体系。

## 当前保留的演进空间

1. 页面状态与表单字段各有唯一存储。字段具备稳定身份、对象数据路径、基础类型与同步规则，业务实体及复杂类型尚未实现。
2. 插槽是物料提供的 React render callback。Schema 定义的独立可复用区块、区块内部状态、对外事件与版本管理尚未加入。
3. 运行计划预解析表达式并收集保守依赖，没有实现动态路径级依赖追踪。复杂对象更新可能影响多个节点，先用性能记录决定优化范围。
4. 能力注册表与物料导入当前为宿主代码。远程包加载、签名、沙箱、依赖锁定和升级转换需要独立设计。
5. 节点属性目前使用有限的运行时类型契约；枚举、联合类型、嵌套对象结构、作用域静态解析可继续细化。
6. 表单内核支持同步/跨字段及整单校验、错误聚合、dirty/touched、显示/禁用、提交取消及重置，以及一层动态数组与稳定行身份。派生计算引用宿主注册的 TypeScript 纯函数；React 继续适配原生事件。嵌套数组和异步校验留待后续，详见 [表单 v0.2](./form-v0.2.md)。

## 验证

测试覆盖真实行为：版本与物料契约拒绝、插槽内重复 ID、实例隔离、类型错误、局部订阅、动作失败终止、取消与晚到结果、空循环和 falsy 数据、原生事件、表单提交、作用域插槽、Hook 状态重置、StrictMode 生命周期及无效 Schema 保留当前应用。
