# 工作台布局与滚动约定

状态：已完成独立评审和交互精简中的布局优化，使用 React + Base UI + Tailwind CSS v4。

## 功能分区

- 全局顶栏 48px：项目标识、可搜索的页面选择器、撤销/重做、文件菜单、编辑/预览。JSON 导入导出与协议入口集中在文件菜单。
- 永久窄侧栏：桌面 44px、手机 40px，以图标承载物料、结构、数据三个纵向 Tab，收起内容时仍可访问。左侧内容默认 224px；点击图标重新打开内容。
- 物料区仅保留搜索和双列网格，整块物料可拖入；空格/Enter 启动键盘拖放，此时才出现落点选择。删除常驻类型、插入位置和添加按钮。Lucide 图标固定 16px，标题对齐。
- 结构树使用紧凑单行，支持折叠、按名称/类型/ID 搜索、定位当前节点。完整技术 ID 在悬浮提示及选中摘要中查看。
- 数据面板集中本页表单模型、字段与校验规则管理。右侧保留绑定选择、字段摘要与“编辑字段设置”入口；数据目标带页面身份，手动切字段后不会被旧快捷入口覆盖。
- 中央只有一行 36px 画布工具栏；画布占据其余空间。选中组件不会强制切换左侧页签或调试视图。
- 右侧默认 304px：选中摘要、主要内容属性和绑定设置。移除结构移动面板；移动由画布/结构树拖放完成。选中框右上角仅放复制和删除图标。标题等常用输入位于首屏。
- 画布先点击选中，再直接拖动组件本体；选中容器可从其子内容起拖。未超过 6px 时仍按点击选择处理。普通鼠标指针，选中后显示抓取指针，不使用十字标和独立画布拖拽手柄。编辑器悬浮提示统一为 Base UI Tooltip。
- 底部调试区默认收起为 32px；展开默认 240px，包含 Schema、页面状态、执行记录，可拖动调高或最大化，与右侧属性同时使用。窄屏调试占满顶栏以下区域，被覆盖画布不接收焦点，Escape/关闭恢复调试页签焦点。

## 尺寸与滚动

应用占满 `100dvh`，`html / body / #root` 不滚动。各级 flex 容器使用 `min-height: 0` 和受限高度；画布、左侧活动面板、右侧属性内容分别只有一层滚动。Schema 外层不滚动，仅文本编辑区承担代码滚动，操作按钮保持可见。

两侧可收起、拖动调宽，也支持方向键、Home/End 调整。左栏允许 192–420px，数据面板至少 280px；右栏偏好允许 280–460px。布局尺寸和收起状态保存到 `localStorage` 的 `dimlu.workbench.layout.v1`；视口变小时计算有效右栏宽度，回到宽屏恢复用户偏好。多指输入锁定当前指针，其他指针不改变正在进行的尺寸调整。

左侧在小于 1000px 或画布剩余空间不足时改为抽屉，右侧小于 760px 改为抽屉。左抽屉为非模态，指针拖动时淡出并允许画布命中，拖放源仍保持挂载与指针捕获；成功插入后关闭。右抽屉使用模态焦点管理。抽屉关闭后回到打开按钮。

编辑器控件 28px，业务控件 32px，触摸环境的抽屉控件适度加大。根字号 16px、正文 13px，未使用 CSS zoom 或整体 transform 缩放。Tailwind 负责基础控件和设计变量；业务物料及拖放几何使用命名样式。

## 草稿与运行时

字段、规则、未应用的属性表达式/JSON、应用 Schema 草稿保存在独立 EditorSession 中，按页面/节点/字段身份索引；切换页签、节点、页面、抽屉或响应式断点后仍可恢复。草稿仅保存于当前应用会话，刷新页面会清除；布局偏好单独持久化。

有效普通属性即时应用，无效输入保留为草稿。字段与 Schema 必须显式保存；底层配置被撤销或修改时，草稿标为过期，保存按钮禁用，必须先“确认使用草稿”或“放弃草稿”。无关文档修改不覆盖字段草稿。Schema 重新载入明确放弃未保存内容。

仅选择组件、调整面板、切换模式和开关抽屉不重建 PageRuntime，也不重建业务 React 组件。有效定义修改、切换页面或主动重置仍按既定语义创建运行实例。TSX 物料继续使用 React props、Hooks 和原生事件；布局和控件库不进入业务 Schema。

## 验证记录

当前 124 项自动测试全部通过；覆盖选中本体拖放阈值、容器拖动与子项点击、键盘落点、图标复制删除、物料精简与纵向侧栏。自动回归覆盖原有 Schema、表单、拖放、历史、运行时及 Base UI 行为，并新增连续插入、草稿保留/冲突、手动字段选择、布局持久化、多指隔离、移动调试焦点与树搜索定位的验证。

上一轮已在 1280×720、1440×900、760×720、390×844 检查全高外壳、抽屉拖放、业务 React 状态保留和调试焦点。加入永久侧栏后，760px 的宽度预算更新为右栏 280px、中央 430px；响应式回归继续由自动测试覆盖。本轮浏览器实测 1942×1262，根宽高等于视口，输入组件跨容器移动、从子内容拖动选中容器、整块物料拖入、撤销、图标复制/删除和自定义提示均通过。新的页面无控制台错误。浏览器尺寸覆盖接口本轮未改变实际视口，因此未将本轮窄屏浏览器复测记为通过。

## 热更新与物料兼容

编辑器共享 Context 在 Vite 热更新中保持身份，避免保留的 Provider 与更新后的消费者断开连接，造成画布无法拖动或隐藏节点占位丢失。选中框使用稳定的画布根元素捕获指针，避免拖动时装饰层变化中断捕获。

物料面板保留 9 个通用组件；摘要、成员行、成员卡片和 React 计数器隐藏于面板，原有示例仍可渲染。注册能力、可插入性和面板可见性分别管理，详细取舍见 [物料库规划](material-library-plan.md)。
